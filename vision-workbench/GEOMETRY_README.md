# 第二阶段：几何参数关联

`geometry.py` 与原有严格标注提取分开执行，读取原文件、同文件同页的第一阶段结果和实际页面图像。当前业务模板包含安装孔径、舌片外宽、绝缘套最小长度、非接触端最大长度、端子总长度、导线绝缘层外径范围。这里“非接触端最大长度”明确指后端至安装孔中心的最大距离；不等同于暴露接触段长度。

CLI 示例（先在服务进程环境设置自己的模型凭据和模型名）：

```sh
python geometry.py --document /path/drawing.pdf --stage-one /path/result.json --page 1 --output /path/new-geometry-run
```

输出目录必须是新目录。`result.json` 为可导入网页的 `geometry-1.0` 候选结果，`audit.json` 为本机脱敏调用记录。不覆盖第一阶段结果。不自动重试，不修改数字或补造单位。结果字段通过仅代表格式、数值引用和来源链接校验，不能证明模型追踪的引线、尺寸对象或坐标正确。

本机工作台流程：上传原文件 → 提取当前页标注，或“导入已有标注 JSON” → “识别六项几何参数” → 点击卡片定位 → 导出几何 JSON。两个提取动作分别发送当前页到服务端配置的模型。每次几何调用使用已上传文档的服务端页面，浏览器不能覆盖路径、模型或模型端点。

来源矩形与引线点是模型估计。明确文字说明中的导线绝缘层外径可以没有几何引线；未明确单位时保留空值。导线截面积和 AWG 不能代替绝缘层外径。

网页静态发布版与本机工作台是两个独立运行环境。公开网页没有直接调用本机模型服务的连接；通过结果 JSON 导入进行衔接。
