# SPECFlow 图纸工作台 0.8.1

用于图纸建库、图文检索、字段与表格候选提取、人工复核、指导书草稿和参考报价。这是浏览器本地辅助工作台，尚未完成参考平台的全部能力。当前采用浏览器 OCR、文字规则与页面外观哈希，并支持导入本机 VLM 的真实提取结果；云端直接模型调用仍待可用的服务账号接通。

## 0.8.1 真实调用与定位复核

补充可审计的协议兼容：模型给出的非标准状态、数字编号和已知英文部件名可规范化；不更改尺寸数值、单位、类别或对象关联。两张开发图纸的原始响应经离线协议回放可导入，分别包含9和14项候选；回放不是新的模型调用，也不是独立准确率评测。随后端子图完整实时调用成功：HTTP 200，用时272.347秒，无协议修正，9项候选和3项未提供项目。逐项原图目视复核支持9项主数值与语义；导线绝缘外径仍无明确单位，1个注释框截断末端。另一张图的复跑在300秒超时，服务稳定性仍需改善。

真实原页核对发现部分模型定位框偏移，因此默认只显示清晰原图；展开“查看模型估计定位（待复核）”才显示原始估计框和引线。REF参考尺寸不能直接作为确定实体尺寸，矩形外包络支持宽×深×高映射。

## 0.8 中文语义参数与受约束的局部建模

参数目录覆盖用户给出的115类几何、压接、间距、PCB、形位和装配参数。目录不是识别准确率承诺：只显示图纸实际候选，保留相同类别的多个部位/视图实例，未知和未归类标注单独展示。主界面使用中文名称、实例及理由，原始英文保留在证据折叠区。支持搜索、分组、原图高亮与来源校验，兼容旧六字段数据。

本机模型工作台可直接选原图运行语义识别，不必先有第一阶段结果。输入含原页和四张有坐标记录的重叠裁剪图；输出geometry-2.0使用115类词典和逐项原文引用。对源单位、引用数值、面积/直径和明显的端点矛盾执行格式/证据校验。校验通过仍不是几何正确性或制造批准。

网页新增三种确定性局部几何：环形接触片、直圆筒段、矩形外包络。用户可查看并调整尺寸映射，生成二维SVG、可旋转三角网格、STL、参数化SCAD及来源JSON。缺少确定名义尺寸、单位未知、只有上/下限、面积/形位公差误用、内外径冲突、跨部件尺寸混合均阻止生成。模型不填造缺失外轮廓/过渡/内部结构，不是任意PDF到完整CAD。

复用核对按类别列出另一份图纸的候选尺寸差异；多孔/多部件对应关系、公差、材料与工艺必须逐项核对，不自动输出可制造结论。公网仍是本浏览器资料库，结果通过JSON导入；没有把本机诊断凭据部署云端。

本次回归及真实素材验证记录见本机诊断报告。自动化测试与少量开发样本不等于115类识别准确率。未训练新的通用神经网络。

## 0.7 几何参数与原图对应

新增“几何参数”视图：安装孔径、舌片外宽、绝缘套最小长度、非接触端最大长度、端子总长度、导线绝缘层外径范围以六张卡片呈现；点击查看标注框、对象框和模型给出的尺寸线端点。结果导入校验原始文件 SHA 和页码，缺失项、无明确单位或公差分别显示，支持高清预览和缩放。

本机视觉工作台新增独立第二阶段“识别六项几何参数”。第一阶段继续保留标注原文，第二阶段根据原图追踪几何对象；公网静态页面当前通过导入第二阶段结果使用该功能，不含云端凭据。实际端子图第二轮调用返回 HTTP 200，用时约31秒，六项均返回候选；绝缘外径单位保留为空，未用导体截面积代替。模型位置仍是近似区域，单张已知样本不代表总体准确率。

## 0.6 视觉结果进入业务流程

先导入原 PDF / 图片，再打开 **视觉识图 → 导入视觉结果 JSON**，选择本机工作台导出的结果。导入操作只在当前浏览器处理，校验文件 SHA-256、页码、证据引用、数值和公差，拒绝不匹配的来源。同一响应不能重复导入，已有人工修改和已复核字段不会被覆盖。视觉字段仍标为待复核；与已有字段可能重复的条目单独提示取舍，不直接进入指导书。

可查看隔离候选、定位原图区域、人工关联尺寸对象/视图/工作状态。页面中的单位声明与通用公差独立生成带来源的参考，只有明确选择目标尺寸并确认来源后才建立人工关联；通用公差不会覆盖专用公差。包装/料号变体表单独展示包装数量、料号和原文，不当作装配 BOM 或报价用量。

默认指导书模板按字段类别接收中性名称的尺寸及技术信息，并保留来源、人工关联及缺失状态。自定义模板仍按明确配置的字段名选择，不自动扩大规则。

公网版本包含上述结果复核流程，不包含用户原图、实际模型响应、私人资料库或 API 密钥。**检查云端状态**可显示当前接口是否配置；不可用时不要将本地导入称作实时云端识图。现有个人诊断令牌仅限本机，未上传网站。

## 0.5 扫描工程图增强

已有图纸在“信息提取与复核”中点击 **增强识别工程图**；新扫描文件导入时默认启用增强。存在文字层但缺少图中标注的 PDF，也可手动运行此功能。英文图默认使用英文 OCR；中文图纸可调整语言。

增强模式使用高清渲染、不同版面分割方式和重叠区域 OCR，保留每轮的原文与位置；解析无标签尺寸、MIN/MAX、DIA、双单位、标题栏、材料和技术注释。可筛选“尺寸与公差”，放大来源预览、查看互相矛盾的候选。重新识别保留人工修改、采纳和否决结果，新结果有差异时单独展示。图纸原件仍只保存在当前浏览器。

真实原始 `8348565.pdf` 从 0 项改善到 **27 项候选**。人工目视金标核对：6/6 尺寸名义值、mm 单位和来源区域正确，3/3 MIN/MAX 正确；但只有 3/6 组尺寸的公差、双单位等元数据完整。两处 ± 公差未可靠结构化，总长英寸对照、图号字符、版本和工作温度仍存在错漏，不能声称完整识图通过。详见 [扫描图纸真实验收](docs/DRAWING_VALIDATION.md)。

## 使用流程

1. **导入建库。** 多选文件或文件夹，导入 PDF / PNG / JPG。保留原文件、SHA-256、导入时间和逐页文本、缩略图、类型、哈希、来源坐标；重复内容跳过。PDF 读取会过滤裁剪区域外的隐藏文本。可选自动 OCR；大型文档宜明确指定需要识别的页码。
2. **检索。** 上传独立查询图纸，也可输入文字或组合使用。调整文字、外观、结构字段权重，多选库文件范围，按页类型/字段类别过滤；默认排除相同内容和演示资料。文件级前三名包含最佳匹配页与证据，查询条件、内容标识及排名可导出。分数只用于候选排序。
3. **提取与复核。** 核对字段值、原文、页码和来源框；尺寸的单位、公差、对象与视图需要确认。可选择 OCR 语言、正交方向、页码和页面区域重新识别；表格去线为试验模式。字段支持修改、采纳、否决和复核历史；复杂图形及缺失字段可人工补录。
4. **BOM 与比对。** 从明确表头及列位置恢复 BOM 候选，核对料号、数量和单位后导出 CSV。管材等长度用量保留小数及单位。比较已提取字段和 BOM 的变化；不同规格的产品不能直接当作修订版本。
5. **指导书。** 八章节模板可配置字段映射、固定说明、规则版本、必需字段和导出条件。输出区分图纸证据、固定模板和规则生成内容；缺失信息明确保留。支持 Markdown / 可打印 HTML，结果始终是待审核草稿，不推测没有来源的工序和生产参数。
6. **参考报价。** 明确输入单价和费用，缺少单价时阻断导出。保存历史记录后，可按料号、名称、材料、单位匹配引用价格，并再次确认适用性；BOM 变化会使旧报价需要重新确认。报价 JSON 记录依据，不能代表供应商承诺。
7. **反馈。** 导出采纳、否决、来源及修订事件的 JSONL，供人工整理标注集。导出反馈不会自动训练模型。
8. **备份恢复。** 导出/恢复解析资料、复核状态、配置与报价历史。备份明确不包含原 PDF 或图片文件；保留原件，需要重新 OCR 时重新提供。恢复不会建立跨浏览器自动同步或团队共享服务。

## 能力边界

输入上限为单文件 200 MiB、PDF 500 页，实际处理时间和内存取决于设备、页数与 OCR 范围。自动补 OCR 的默认页数上限为 10 页；其余页应明确选择后另行处理。ZIP / STEP / DWG 不走当前 PDF/图片解析路径，需要先解压或导出 PDF。

有文本层不代表信息完整，尤其可能缺少图中型号和表格数字。OCR 置信度、外观相似分、可读取率和字段正确率是不同指标。特殊符号、尺寸引线、形位公差、投影关系、多状态配合和表格型号关联仍需人工核对；不能承诺任意图纸自动理解或 90% 准确率。团队共享资产库、企业权限、PLM / ERP / CRM 接口、历史采购数据、自动微调、三维几何/PMI 与知识图谱尚未接入。
